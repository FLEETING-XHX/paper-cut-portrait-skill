# 核心提示词

每次读原图后补充动态描述；下列内容用于生成单独插画，拼接由脚本完成。

将提供的原始照片转译成暖纸底、无五官的剪纸版画拼贴插画，仅生成插画画面。

忠实保留原照片中的人物数量、左右顺序、前后遮挡关系、身体朝向、头部倾斜、关键手势和自拍透视。通过发型、发色、眼镜形状、服装主色及轮廓保留人物之间的区别，不增加、删除或合并人物。若手臂因自拍透视靠近镜头，保留其方向和视觉关系，不将构图改成整齐排列的证件照。

用简洁、略带棱角的不规则纸片色块构成人物。脸部使用暖纸色或浅肤色的平面，完全省略眼睛、鼻子、嘴巴和眉毛以及写实面部阴影；保留照片中实际存在的眼镜，以简洁深色线条表现。头发用有缺口的块面表达，服装简化为大色块，保留主要配色和有辨识度的拼接结构，省略可读文字和复杂标志。

采用暖米白、旧象牙色纸张背景，带细微纸纤维和自然颗粒。以炭黑、纸色以及从原照片提取的少量服装主色构成有限色板。色块表面呈现粗粝的版画油墨、干刷、刮擦、局部掉墨和露纸效果；边缘像手工剪纸与撕纸，略不规则，局部留有细窄纸色缝隙。纹理跟随色块和笔触自然变化。

移除原照片中的复杂环境，用有呼吸感的纸面留白承托人物。可加入少量与服装配色呼应的粗糙几何纸块，但不遮挡人物或抢占主体。整体呈现克制、有手工感的编辑插画和复古印刷拼贴气质。

避免写实人脸、动漫五官、三维效果、光滑矢量边缘、渐变塑料质感、厚重投影、复杂背景，以及整幅画面统一覆盖的噪点滤镜。

画面中不要出现任何可读文字、字母、数字、标语、标题、签名或水印。不要生成原图与插画的上下拼接版。

## 动态描述

按本次照片观察填写：

- 人物：准确人数；从左到右的前后位置、发色发型和眼镜。
- 动作：关键手势属于谁，哪只手在哪里；自拍手臂方向。
- 配色：服装主色及少量辅色，保留明显配色结构。
- 输出：仅插画，与原图接近的宽高比。
- 图像角色：第一个输入为原图，其他输入如有则仅作风格参考，忽略参考的后期文字。
